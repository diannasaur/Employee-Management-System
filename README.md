# Employee Management System

A C# console program that reads employee data from a file, processes it using delegates to filter employees by salary and experience, applies bonuses to eligible employees, and generates a summarized output report with updated salary information.

## Features

- Reads employee records from an input file
- Uses C# delegates to filter employees based on configurable salary and experience criteria
- Applies bonus calculations to employees who meet eligibility rules
- Generates a summarized report showing updated salary information
